# JSON Body Generator

Генератор тела запроса для тестирования REST API. Выбираешь схему в дропдауне на
фронте — бэкенд генерирует JSON, заполненный правдоподобными данными (через Faker)
согласно JSON Schema.

## Запуск

```bash
docker-compose up --build
```

- Фронтенд: http://localhost:8080
- Бэкенд (Swagger): http://localhost:8000/docs

## Как добавить новую схему

1. Положи файл `<любое_имя>.json` в `backend/schemas/`.
2. Обнови страницу фронтенда — новая схема появится в дропдауне сразу,
   пересборка бэкенда не нужна (папка примонтирована как volume).

Имя файла (без `.json`) — это `id` схемы. Поля `title` и `description` внутри
JSON — то, что увидит пользователь в дропдауне.

### Поддерживаемые ключевые слова JSON Schema

- `type`: `object`, `array`, `string`, `integer`, `number`, `boolean`, `null`
- `properties`, `required` — для `object`
- `items`, `minItems`, `maxItems` — для `array`
- `format` (`email`, `date`, `date-time`, `uuid`, `uri`, `hostname`, `ipv4`, `ipv6`, `phone`)
- `enum` — случайный выбор одного из значений
- `const` — фиксированное значение
- `example` / `default` — если задано, используется как есть (Faker не трогает поле)
- `minimum` / `maximum` — для чисел
- `minLength` / `maxLength` — для строк

Если для строкового поля не задан `format`, генератор пытается угадать смысл поля
по его имени (`email`, `first_name`, `phone`, `address`, `price` и т.д.) и подобрать
подходящий Faker-метод. Если имя ничего не подсказывает — генерируется случайный текст.

### Ограничения v1

- `$ref` / `$defs` не резолвятся — схемы должны быть "плоскими" (без ссылок на
  переиспользуемые определения). Легко добавить при необходимости.
- Валидация сгенерированного JSON против схемы (через `jsonschema`) не подключена —
  генератор и так следует схеме, но для сложных кастомных `pattern` это не проверяется.

## Структура проекта

```
backend/
  app/
    main.py       # FastAPI, эндпоинты
    generator.py  # JSON Schema -> заполненный JSON (Faker)
    registry.py   # сканирование папки schemas/
  schemas/        # .json схемы — сюда добавляешь свои
frontend/
  src/
    App.tsx       # дропдаун + кнопка "Сгенерировать" + копирование
    api.ts        # вызовы к бэкенду
```
